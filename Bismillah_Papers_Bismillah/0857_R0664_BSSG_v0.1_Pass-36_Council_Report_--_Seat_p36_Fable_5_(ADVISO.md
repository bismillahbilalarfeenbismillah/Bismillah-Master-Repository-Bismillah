### Angle 1 -- `_apply_narrowing` (L1949) widening algebra with empty `_held`

The previous-is-None branch (L1946-L1955) does:
`_held = self.state.contract_ceiling.get(session); if _held is not None
and not (new_ceiling <= _held): terminalize E-AUTHORITY-WIDENING`.

`Authority.__le__` (L549-L550) is a pure subset test on both fields:
`self.effects <= other.effects and self.targets <= other.targets`. It is
NOT `is_empty()`, NOT `contains`. When `_held = Authority([], [])`:

| test | result |
|---|---|
| `Authority([], []) <= Authority([], [])` | True (re-widen to nothing is not widening) |
| `Authority(['READ'], []) <= Authority([], [])` | False (terminalizes) |
| `Authority([], ['tgt']) <= Authority([], [])` | False (terminalizes) |
| `Authority(['READ'], ['tgt']) <= Authority([], [])` | False (terminalizes) |

So an empty `_held` correctly bounds ANY non-empty re-establishment to
"nothing can widen to something." The widening check is the exact
subset relation `new_ceiling <= _held`, and the algebra is sound for the
empty held authority. This is the load-bearing property the class fix
depends on, and it holds. Basis: substrate `bssg_gate.py:L549-L550,
L1946-L1955`; spec X7 claim `BSSG_v0_1_CANONICAL_SPEC_DRAFT.pplx.md:L518`
("proper where the prior ceiling was non-empty").

## Advisory findings (six-element format; advisory-only)

**F-FB-1** MEDIUM (advisory-only) -- Mint-fault-first session cannot
recover any authority through a lift; only a fresh session recovers.

- **Locus:** `bssg_gate.py:L889-L899` (`_issuance_failure` empty-init),
  L1946-L1955 (`_apply_narrowing` empty-`_held` bound); reproduced by
  `fable5_class_fix_probe.py` angle2_3 (`r4_honest_rewiden_decision =
  DENY_FALSE`).
- **Substance:** The design surface says the fix is "fail-closed default"
  (comment L889-L893); the substrate behavior is that a session whose
  FIRST establish suffered a mint fault has `contract_ceiling =
  Authority([], [])`, so after a legitimately accepted `LIFT_TERMINAL_STATE`
  the honest re-widen to even a contract-registered effect (READ) is
  DENIED as `E-AUTHORITY-WIDENING`. The lift is accepted but restores
  nothing usable. This is intended (the session "never successfully held
  any authority"), but it is a real liveness property: recovery of the
  original session is impossible; the subject must open a new session.
- **Disposition:** No code change required (behavior is correct and
  fail-closed). Documentation route: state explicitly in the spec
  recovery narrative (near `BSSG_v0_1_CANONICAL_SPEC_DRAFT.pplx.md:L447`,
  R-1 LIFT semantics) that a lift of a never-demonstrated session restores
  the empty ceiling and that new-session establishment is the recovery
  path. Advisory to the panel; not a HALT condition.
- **Cross-reference:** CE175 (`bssg_counterexamples.py`, F-GS-1 mint
  fault), CE162 (honest recovery), `bayyinah_severity-rubric.md`
  MEDIUM band (methodology-fidelity / behavior-documentation gap, not a
  ship blocker).

**F-FB-2** LOW (advisory-only) -- `Authority.is_empty()` uses OR
semantics, orthogonal to but adjacent to the class fix.

- **Locus:** `bssg_gate.py:L565-L566` (`is_empty` = `not self.effects or
  not self.targets`); consumed only at L1960 (`_apply_narrowing`
  nonstrict-narrowing guard `not previous.is_empty()`).
- **Substance:** `is_empty()` returns True when EITHER field is empty, so
  an effect-only `Authority(['READ'], [])` reports `is_empty() == True`
  yet is NOT `<= Authority([], [])`. The class-fix empty entry
  `Authority([], [])` is fully empty on both fields, so this OR-semantics
  never mis-fires for the class fix (the L1949 held-check uses `<=`, not
  `is_empty`). The observation is that `is_empty()` and the `<=` floor use
  different notions of "empty"; they do not collide today because
  `ceiling_for_health` always populates both fields from contract data and
  `contract_ceiling` never carries a one-field-only Authority.
- **Disposition:** No change required. Optional hygiene: add a one-line
  comment at L565 noting the OR-semantics is deliberate (any missing
  dimension means the ceiling authorizes nothing) so a future reader does
  not assume AND-semantics and introduce a one-field-only
  `contract_ceiling` write.
- **Cross-reference:** Angle 1 algebra table above; `bayyinah_severity-
  rubric.md` LOW band (polish / future-reader hygiene).
