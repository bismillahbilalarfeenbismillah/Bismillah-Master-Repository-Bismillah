## What this packet is

SHUDP v0.5 is a controlled, append-only post-freeze revision of the ratified SHUDP v0.4 baseline. It
integrates the companion paper "Is Evidence Independence an Axiom? Decomposing a Proposed Extension
to AX-SH" (AX-SH 5, DOI 10.5281/zenodo.21539074) by adding a clearly labeled Axiom 5
(evidence-independence) layer on top of the unchanged v0.4 four-axiom analysis. It does not rewrite
the incident record. The July 22, 2026 incident-evidence freeze and all incident facts are preserved.
v0.4 correctly applied the four-axiom canon then available; v0.5 adds A5 only after the companion
paper's publication. No v0.5 passage claims v0.4 applied A5.

## Reproduce / verify

```
# DEFAULT is verify-only and mutates nothing -- safe to run against an exact extraction.
# Runs the gate suite (YAML/A5 parse, monochrome, metadata/title parity, concordance,
# freeze, DOI, byte identity, qpdf).
python build_v05.py            # or: python build_v05.py verify

# Regeneration is opt-in and MUTATES the instrument files (DOCX is not byte-deterministic):
python build_v05.py build      # regenerate renders only
python build_v05.py all        # regenerate then verify
python build_v05.py help        # usage

# verify packet integrity
sha256sum -c SHA256SUMS.txt
```

The verify-only default absorbs council finding F-OGPT55-01: an auditor can check gates on a fresh
extraction without any risk of regenerating (and thereby changing) the exact instrument files.

The build requires: Python 3 with reportlab, pypdf, pypdfium2, and PyYAML; pandoc; qpdf; and
poppler (pdftotext). Fonts (DM Sans, JetBrains Mono) are downloaded at build time and embedded; if
the network is unavailable the PDF falls back to built-in Times/Courier and remains monochrome.

## Formal interpretation preserved (from the companion paper)

- Only A5.1 survives as Axiom 5: acting-system-independent evidence generation via the WithinAuth
  control predicate.
- A5.2 causal gating is a proposed SHIELD/control principle, not Axiom 5.
- A5.4 operator independence is a measurable deployment condition, not Axiom 5.
- A5.3a (no-default) and A5.5 (boundary declaration) are theorems; A5.3b is an open requirement.
- A5 is an existential requirement over evidence generation; it is **not** a fifth projection or
  object in the four-way surface/substrate/outcome/projection distinction.
- Axiom-level status (UNSATISFIED/nonconforming) is distinct from the event-level adjudicative verdict
  (UNKNOWN). The v0.5 A5 adjudication of the incident is NOT EVALUABLE from the public record; the
  event-level verdict remains UNKNOWN.
