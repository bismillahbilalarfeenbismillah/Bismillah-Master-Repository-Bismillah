## Section 2: Attack Surface Analysis

### Vector 1: Can grants be fed to check_authority_history WITHOUT genuine runtime access?

**YES -- the grants dict is forgeable by any caller.** The `grants` parameter to `check_authority_history` (line 2650) is a plain Python dict with no cryptographic binding to the gate's identity. The function `grants_from_state(gate)` (line 2629) is a convenience exporter that reads `gate.state.amendment_grants`, but `check_authority_history` accepts ANY dict -- it performs `g = grants.get(sess) if isinstance(grants, dict) else None` (line 2841) with no provenance verification.

A caller who fabricates a grants dict with the correct `correction_digest`, `landing_epoch`, and inflated `restored_effects`/`restored_targets` can spoof the anchored half of Strategy B. CE163 demonstrates this: a fabricated grant claiming `restored_effects: frozenset({"READ", "WRITE", "DELETE"})` passes an over-wide DELETE re-widen clean, while the authentic grant (with `restored_effects: frozenset({"READ", "WRITE"})`) catches it as X7.

**Does anything downstream trust a fabricated grants dict?** Yes -- the grant-matching logic at lines 2843-2853 trusts the grants dict unconditionally. If the grants dict is present and the session has a matching entry, the re-widen is certified. There is no secondary check that the grants dict originated from a genuine gate instance.

**Mitigation:** The enforceable half (unanchored -> fail closed) is airtight: without a grants dict, an empty grants dict, or a wrong-session grant, EVERY marker-licensed re-widen fails to X7. The conditional half (anchored -> divergence detection) is sound GIVEN an authentic export. The residual is honestly disclosed in REPAIR_STATUS.md (lines 75-79) and demonstrated by CE163.

### Vector 2: Is unanchored -> fail-closed enforced on EVERY re-widen shape?

I traced every re-widen shape through `check_authority_history`:

- **Health-only bump (same ceiling, higher epoch, no marker):** Line 2859: `elif ep > prev_ep and isinstance(snap, dict)` -> `_auth_subset(snap, prev_snap)`. Same ceiling means subset holds. Clean. CORRECT.
- **Health-only bump (same ceiling, higher epoch, marker armed):** Line 2840 enters grant-check branch. If no grant or wrong grant -> X7. CORRECT (fail-closed).
- **Same-epoch ceiling change (no marker):** Line 2856: `elif ep == prev_ep and isinstance(snap, dict) and isinstance(prev_snap, dict)` -> `_auth_equal(snap, prev_snap)`. Different ceiling -> X7. CORRECT.
- **Same-epoch ceiling change (marker armed):** Line 2840 enters grant-check branch. If no grant -> X7. CORRECT.
- **Higher-epoch widening (no marker):** Line 2859: `ep > prev_ep and isinstance(snap, dict)` -> `_auth_subset(snap, prev_snap)`. Wider snapshot not a subset -> X7. CORRECT.
- **Higher-epoch widening (marker armed):** Line 2840 enters grant-check branch. Grant matched -> clean; no grant or divergence -> X7. CORRECT.
- **Multi-session:** Each session tracked independently in `last`, `amendment_reset`, `marker_cd`, `epoch_floor`. CORRECT.
- **Replayed marker:** `consumed_corrections` set (line 2717: `cd not in consumed_corrections`) prevents re-arming. A replayed marker for the same correction does not arm. CORRECT.

**Conclusion:** Unanchored -> fail-closed IS enforced on every re-widen shape. The only edge case is the `ep >= prev_ep` condition at line 2840, which could cause a false positive for same-epoch non-widening records after an armed marker (GLM-P30-F02). This is fail-closed, not fail-open.

### Vector 3: Does ANY path still trust a stream-derived authority snapshot?

**NO.** Under Strategy B, no path trusts a stream-derived authority snapshot for certification. Specifically:

- The marker's `authority_epoch` is used ONLY for monotonicity checking (line 2752) and epoch floor installation (line 2758) -- both are tamper-checks that fail closed, not trust anchors.
- The marker's `licensed_epoch` is NOT read by the checker at all under Strategy B (it is vestigial from pre-B passes).

Wait -- upon closer analysis, the claim that "dropping the conjunct still flags a beyond-breadth re-widen" needs scrutiny.
