## Fixed this pass (94/94 counterexamples; 342 tests; model-check PASS; verifier 10 PASS / 1 WARN / 0 FAIL)

- **GPT-01 (BLOCKER) + KIMI-P15-01 -- pre-nonce clock-fault abort was not terminal.** The clock (a fallible
  evaluator) was read before nonce consumption, so a transient fault aborted before the nonce was consumed
  and an identical retry re-authorized. Fix: no fallible evaluator runs before structural admission + nonce
  consumption; the clock is read only after the nonce is consumed and the snapshot recorded; the abort
  handler terminalizes the post-admission snapshot. `CE89`.
- **GPT-02 (BLOCKER) -- the pass-15 abort rollback over-restored security-monotonic state.** The blanket
  rollback rewound authenticated epoch advances and authenticated narrowing that must survive a token-mint
  failure to invalidate older grants; restoring them revived a stale WRITE token. Fix: the blanket rollback
  is removed -- an authenticated monotonic advance/narrowing is a security fact that persists across an
  abort; only issuance is incomplete, and it committed nothing. `CE90`.
- **GPT-03 (BLOCKER) + GLM-P14/P16/P17 + KIMI-P15-03 -- evidence-independent TargetAllowed FALSE suppressed
  on the malformed-evidence path.** `TargetAllowed` was split into `_target_independent` (canonical, class,
  contract scope -- no ceiling) and the ceiling component; the malformed-evidence helper now evaluates the
  independent predicates and propagates any FALSE into the frozen kernel, so a target provably outside the
  contract is DENY_FALSE, not DENY_UNKNOWN. `CE91`.
- **GPT-04 (BLOCKER) + GLM-P19 + KIMI-P15-04 -- the pass-15 collision record was kernel-inconsistent.** It
  carried five TRUE conjuncts but decision=DENY_UNKNOWN (the kernel maps five TRUE to ALLOW). Fix: a
  token-factory collision is a POST-kernel issuance failure recorded by `_issuance_failure`: the decision is
  the true kernel classification (ALLOW), and the mint failure is a distinct, non-redeemable
  `issuance_status="FAILED_NO_EFFECT"` with no authorization_receipt and a terminal snapshot. The model
  checker now drives a collision and asserts recorded_decision == kernel_decision(recorded_conjuncts) on
  every kernel-decision record. `CE39` (rewritten), model-check REFINE line.
- **GPT-05 (BLOCKER) -- unqualified safety claim leaked in the spec.** "This is safe and operationally
  expensive" became "This is authority-reducing and operationally expensive; no safety outcome is claimed";
  the Section 1.2 disclaimer was reworded to avoid the same phrase; G5 gained an `is safe` prohibited
  pattern (negated disclaimers reworded so the affirmative form is the only match).
- **GPT-06 (MAJOR) -- X1-X8 mechanical-coverage claim overstated.** Implemented `check_allow_receipt` (X8:
  an ALLOW receipt carries exactly five TRUE conjuncts and an empty reason list -- catches the forged
  EvidenceCurrent=UNKNOWN receipt), `check_authority_history` (X7: per-session monotone authority_epoch and
  a post-degradation ceiling that is a proper subset), and `check_single_redemption` (X4 redeemed-at-most-
  once). Each has positive and negative test vectors and is re-exercised by new verifier gate G11; spec
  20.4 now names every checker. The X8 checker is also invoked inside `check_cross_record_invariants`, so a
  forged ALLOW receipt is caught by the cross-record invariant that scans real receipts, not only by the
  standalone checker. `CE92`.
- **GPT-07 (MAJOR) -- ordinary rejected amendments were not recorded.** A failed lift-terminal-state attempt
  was invisible in state.records. Fix: every ordinary amendment rejection is routed through
  `_amendment_reject`, which appends a `bssg.correction-outcome` record. `CE93`.
- **GLM-P15 -- stale code comment.** The pass-14 "DENY_UNKNOWN MUST NOT terminalize" comment contradicted
  spec 6.3 and the code; replaced with the terminal-for-every-deny statement.
- **KIMI-P15-05 -- token-id guard admitted schema-invalid artifacts.** The factory-token guard now enforces
  the receipt schema bounds (8 <= len <= 128) so a too-short token is refused rather than minted into a
  schema-invalid receipt. `CE94`.
