## Program history (for the paper's methodology and results sections)

### The artifact
BSSG (Bounded Structural Safety Gate) is a reference implementation of a decision gate
whose kernel equation is:
  Allow(r) iff ContractMatch AND EffectTypeValid AND TargetAllowed AND WitnessHealthy AND EvidenceCurrent
Three-valued (TRUE/FALSE/UNKNOWN); UNKNOWN never satisfies; FALSE dominates order-independently.

### The defect trajectory (the paper's central empirical finding)
34 consecutive instances of the same structural pattern: the producer's (Claude) fix for a
ceiling-poison bypass shipped incomplete one level deeper. Each instance was found by a
different external seat, reproduced on canonical bytes, and fixed.

| Instance | Round | Found by | What it was |
|---|---|---|---|
| 1-29 | V1-V29 | Various | Pre-convergence defects (see REPAIR_STATUS for full history) |

| 31 | V31 | Kimi K3 | ALLOWed-degraded ceiling-poison (ALLOWED degraded writes HEALTHY ceiling) |

| 34 | Council R2 | Gemini 3.1 Pro | Degraded-first absence (first DEGRADED ALLOW has no ceiling entry) |

The CLASS FIX (pass-36): unconditional empty-Authority init at the top of every ALLOW path,
before any conditional. The invariant: _held is NEVER None after any ALLOW decision. This
closes the class structurally rather than case-by-case. Confirmed by 5 vendor families
across multiple rounds.

### Relevance context
JadePuffer (Dark Reading, July 6 2026): first documented end-to-end LLM-driven ransomware
attack. An agentic threat actor autonomously exploited a Langflow flaw, pivoted to a
production database, exfiltrated data, and encrypted systems. BSSG addresses the class of
threat JadePuffer exemplifies: the control plane sits between the agent's reasoning and the
consequential effect, checking authorization against externally held evidence. BSSG does NOT
claim it would have stopped JadePuffer -- that is a counterfactual requiring interposition
that has not been demonstrated.
