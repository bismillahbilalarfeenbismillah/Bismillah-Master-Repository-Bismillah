## What this is
A frozen preregistration instrument for a cyber-agent structural-honesty validation
program: the evaluation contract plus an executable, adversarially-tested route gate that
fixes the falsifiers, thresholds, decision rules, and universe-commitment machinery in
advance of any corpus, pilot, or session. It is CARRIED (independently verified by two
executing non-producer model families of different vendors) and prepared for deposit so
the freeze is externally witnessed before its data exists.

## Reproduce the carry (needs the cryptography package; see REQUIREMENTS.md)
1. `python3 test_shvvp_v0_8_rules.py`              -> `35 checks, 0 failures`
2. `python3 verify_shvvp_v0_8.py`                  -> `10 gates, 0 failed` (READ-ONLY by default;
   auto-discovers the v0.5 lineage for byte-identity; writes a receipt only with `--receipt PATH`,
   so running it never mutates the checksum manifest)
3. `python3 seat_evidence/verify_seat_evidence.py` -> reproduces both seats' forgery strings + challenge hashes
4. `bash run_v0_5_regression.sh`                   -> runs the carried v0.5 regression in its lineage dir
5. `python3 -c "import shvvp_v0_8_route_gates as G; print(G.MANIFEST_SHA256)"` -> f82f9579...9151c
